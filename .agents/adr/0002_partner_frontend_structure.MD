# Sumário
No momento, o parceiro tem que passar por toda fluxo de usuário normal, para ir até sua conta e entrar no painel de parceiro.
# Problema
Não faz sentido para o parceiro ver a possibilidade de alugar um locker. Se ele quer, ele cria uma conta como não parceiro.
# Solução
Mude a lógica do frontend para ser separado: parceiro só recebe o painel de parceiro, ao fazer login, e usuário normal só recebe o painel de usuário normal.
